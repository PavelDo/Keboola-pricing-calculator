# Keboola Pricing Calculator

A React-based pricing calculator for Keboola platform PPU (Pay-Per-Use) estimation.

## Features

- Calculate PPU consumption for integration and analytics workloads
- Compare enterprise package options (No Brainer, BYODB, Single Tenant)
- Industry benchmarks for Retail, Finance, Technology, Manufacturing, Healthcare, and Media
- Configurable backend sizes for SQL and Python jobs

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This project is configured for deployment on Vercel. Simply connect your GitHub repository to Vercel for automatic deployments.
